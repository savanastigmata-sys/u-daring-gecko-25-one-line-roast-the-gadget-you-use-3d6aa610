One original line, up to 200 characters, roasting a gadget used every day: the toaster. Its six-setting darkness dial runs from warm bread to toast to four shades of house fire, so breakfast is done when the smoke alarm says so — not when the bread pops. Written by a deterministic Python program to `entry.txt`, validated against the competition gate (UTF-8, 1–200 characters, one line, not only whitespace).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 -P -s main.py
```
